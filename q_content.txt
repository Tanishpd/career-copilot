<h3>Rotate Array</h3>
<p><strong>Difficulty:</strong> Medium</p>
<h4>Problem Description</h4>
<p>Given an array of integers <code>nums</code> and a non-negative integer <code>k</code>, rotate the array to the right by <code>k</code> steps. If <code>k</code> is greater than the size of the array, the effective rotation should be <code>k % n</code>.</p>
<h4>Input Format</h4>
<p>The first line contains an integer <code>n</code>, representing the number of elements in the array.<br>The second line contains <code>n</code> space-separated integers representing the array elements.<br>The third line contains an integer <code>k</code>, the number of steps to rotate.</p>
<h4>Output Format</h4>
<p>Print the elements of the rotated array separated by a single space.</p>
