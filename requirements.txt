# Career-Copilot — Python dependencies

# TensorFlow is pinned to 2.15.1, the last release that defaults to Keras 2.
# camera.py builds a YOLOv3 model with the Keras functional API; TF 2.16+
# switches to Keras 3 and would break it. The highest patch level required
# across the 402 tensorflow advisories was 2.12.1, so 2.15.1 clears all of
# them without taking on Keras 3.
#
# RUNTIME: Python 3.10–3.11.
#   TF 2.15 publishes no 3.12+ wheels (upper bound).
#   Pillow 12.x requires >=3.10 (lower bound) — needed to clear its advisories.
#   python3.11 -m venv venv && source venv/bin/activate
#
# These pins are mutually consistent — see MIGRATION.md. Bumping any one of
# them in isolation can break the set (e.g. TF 2.12+ requires numpy >= 1.23.5,
# and Flask 3 requires Flask-WTF >= 1.0).
